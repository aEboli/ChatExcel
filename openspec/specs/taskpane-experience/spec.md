# taskpane-experience Specification

## Purpose
定义 ChatExcel 任务窗格中可访问、低干扰且一致的对话、审批、恢复、历史预览和运行状态体验要求，确保不同窗口尺寸下的文本、状态和操作记录始终清晰、可控且不遮挡核心工作流。
## Requirements
### Requirement: 提供低干扰页脚彩蛋

任务窗格 SHALL 在输入区下方提供一个固定高度的页脚彩蛋入口；装饰场景 MUST 使用打包的本地 CSS 和本地人物图，不得依赖外部脚本、网络图片或字体，并 MUST 尊重键盘和 reduced-motion 设置。

#### Scenario: 探索页脚

- **WHEN** 用户悬停或键盘聚焦 ChatEx 页脚入口
- **THEN** 基线、田野和六个本地人物图角色提高可见度，且不遮挡输入区、操作记录或对话内容

#### Scenario: 点击固定彩蛋

- **WHEN** 用户点击页脚入口
- **THEN** 彩蛋进入或退出活动状态，入口更新 `aria-pressed` 和可操作提示，主聊天流程不改变

#### Scenario: 用户偏好减少动效

- **WHEN** 浏览器启用 `prefers-reduced-motion: reduce`
- **THEN** 人物图角色不持续横向运动，入口和基线仍保持可见且可操作

#### Scenario: 离线显示人物图

- **WHEN** 任务窗格在无网络连接的本地加载项运行时打开
- **THEN** 六个角色均从打包的本地静态资源加载，不产生外部图片请求

### Requirement: 历史预览只表示实际执行结果
任务窗格 MUST 仅在工具输出确认成功且确有可预览目标时从工作簿结果构造网格或图表预览。被用户拒绝、参数校验失败或执行失败的修改操作 MUST 显示明确的只读失败状态，且不得从请求参数展示仿真的已写入数据。

#### Scenario: 用户拒绝矩阵写入
- **WHEN** 工具输出为 `USER_DENIED`，但请求参数包含二维 values 或 formulas
- **THEN** 历史记录显示拒绝状态而非单元格网格，工作簿仍保持未修改的事实对用户可见

#### Scenario: 写入执行失败
- **WHEN** 工具输出为执行失败且携带原始写入参数
- **THEN** 历史预览显示失败说明，不渲染这些参数为已写入的范围

### Requirement: 输入区提供图片附件交互

任务窗格输入区 SHALL 在不产生横向溢出的前提下容纳附件缩略图、删除动作和放大模态层；控件 MUST 提供可读的中文标题、键盘焦点和 reduced-motion 兼容的状态反馈。

#### Scenario: 窄任务窗格显示附件

- **WHEN** 任务窗格宽度为 320 CSS 像素且存在一张或多张待发送图片
- **THEN** 缩略图在输入区内换行或横向滚动，不遮挡文本输入、发送和审批控件

#### Scenario: 减少动效偏好

- **WHEN** 浏览器启用 `prefers-reduced-motion: reduce`
- **THEN** 附件进入和模态层显示不使用持续动画，图片仍可访问、删除和放大

### Requirement: 任务窗格提供紧凑且可读的布局密度

任务窗格 SHALL 通过减少固定区和非必要留白，为对话内容保留更多可用空间；正文消息字号 MUST 保持至少 12px、行高至少 17px，桌面端常用交互控件高度 MUST 至少为 24 CSS 像素。紧凑布局不得改变现有键盘焦点、滚动、附件或 reduced-motion 行为。

#### Scenario: 400px 任务窗格使用紧凑基线

- **WHEN** 任务窗格在宽度 400 CSS 像素、高度 900 CSS 像素下打开
- **THEN** 顶部栏、操作记录、composer 和页脚按紧凑基线渲染，对话区获得比原基线更多的可用高度，且 `body.scrollWidth` 等于 `body.clientWidth`

#### Scenario: 320px 窄任务窗格不产生溢出

- **WHEN** 任务窗格在宽度 320 CSS 像素、高度 700 CSS 像素下打开，并显示消息、操作记录或附件控件
- **THEN** 文本在容器内换行或按既有规则滚动，任何核心控件不被遮挡，且页面不出现横向滚动

#### Scenario: 紧凑控件仍可操作

- **WHEN** 用户使用鼠标或键盘访问发送、审批、模式、操作记录和设置控件
- **THEN** 每个控件的可见焦点仍然存在，桌面端命中区域高度至少为 24 CSS 像素，交互状态与紧凑调整前一致
