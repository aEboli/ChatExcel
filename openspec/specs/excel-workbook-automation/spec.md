# Excel 工作簿自动化规格

## Purpose

定义本地 Agent 在当前 Microsoft Excel 工作簿中的读取、受控修改、验证和操作审计行为。
## Requirements
### Requirement: 读取当前工作簿上下文
加载项 SHALL 提供工作簿信息、当前选区和指定范围读取工具，并返回地址、值、公式、数字格式和必要的尺寸信息。

#### Scenario: 读取指定工作表范围
- **WHEN** 模型请求现有工作表的有效 A1 范围
- **THEN** 工具返回准确的工作表地址、二维值、公式和数字格式而不修改工作簿

#### Scenario: 拒绝过大读取
- **WHEN** 请求范围超过配置的最大单元格数
- **THEN** 工具返回要求缩小范围的错误且不读取整张工作表内容

#### Scenario: 非单元格对象被选中
- **WHEN** 图表等非单元格对象被选中且工作簿信息工具无法取得范围选区
- **THEN** 工具返回活动单元格并标记选择模式，而不把明确的无效选区错误扩展为整个工作簿信息失败

### Requirement: 修改型工具需要确认
加载项 MUST 在执行值、公式、格式、清除、表格、图表、排序或工作表变更前显示工具名和参数，并且 MUST 仅在用户明确批准后执行。

#### Scenario: 用户拒绝写入
- **WHEN** 模型请求写入范围且用户选择拒绝
- **THEN** 工作簿保持不变并向模型返回用户拒绝结果

#### Scenario: 用户批准写入
- **WHEN** 用户批准参数有效的写入工具
- **THEN** 加载项执行一次对应 Office.js 操作并返回实际目标地址和成功状态

### Requirement: 支持核心工作簿操作
加载项 SHALL 支持批量写值、批量写公式、范围格式、数字格式、自动列宽行高、清除范围、添加或重命名工作表、创建 Excel 表格、创建图表和范围排序。

#### Scenario: 创建带公式和格式的结果表
- **WHEN** 用户批准模型写入二维数据、公式、数字格式并创建表格
- **THEN** 目标区域包含可计算公式、类型正确的值和原生 Excel 表格对象

#### Scenario: 从数据区域创建图表
- **WHEN** 用户批准包含有效数据范围、图表类型、标题和位置的图表工具
- **THEN** 活动工作表出现引用该范围的原生 Excel 图表

### Requirement: 工具执行失败关闭
加载项 MUST 验证工作表、范围、二维数组尺寸、颜色、图表类型和排序索引；数字格式工具 MUST 在创建 `numberFormat` 二维矩阵前加载实际范围尺寸，并拒绝超过 5,000 个单元格的请求。验证或执行失败时 MUST NOT 执行未经验证的操作或留下已知部分写入，并 SHALL 把结构化错误作为工具结果返回模型，使 Agent 在未被用户取消且未达到步骤上限时可以修正参数、缩小范围或分块继续。

#### Scenario: 二维数组尺寸不匹配
- **WHEN** 写入值或公式的数组尺寸与目标范围不一致
- **THEN** 工具返回参数错误且目标范围保持不变，Agent 可以根据实际尺寸修正调用后继续任务

#### Scenario: 工具执行时工作表不存在
- **WHEN** 已通过参数 Schema 的工具引用不存在的工作表
- **THEN** 执行器不修改其他工作表并返回结构化错误，Agent 可以先读取工作簿信息再重试

#### Scenario: 拒绝超大的数字格式范围
- **WHEN** 模型请求对实际单元格数超过 5,000 的范围设置数字格式，包括整列或整行地址
- **THEN** 执行器在构造二维格式矩阵前返回 `NUMBER_FORMAT_RANGE_TOO_LARGE`，不修改工作簿，Agent 可以缩小或分块重试

#### Scenario: 设置安全范围的数字格式
- **WHEN** 模型请求对不超过 5,000 个实际单元格的有效范围设置数字格式并获得批准
- **THEN** 执行器只构造匹配该范围尺寸的二维格式矩阵，并执行一次 Office.js 数字格式赋值

### Requirement: 显示操作审计记录
任务窗格 SHALL 在当前会话中显示每个工具的名称、状态、目标和结果摘要，并且 SHALL 在刷新后清除这些记录。

#### Scenario: 完成多步工作簿任务
- **WHEN** Agent 连续执行读取、写入和格式工具
- **THEN** 当前任务窗格按顺序显示各工具的批准状态和执行结果

### Requirement: 提供非持久化历史视觉预览
任务窗格 MUST 在每个工具步骤完成后，为其受影响的范围或图表保留当前页面内存中的只读视觉预览。点击任意操作记录时，任务窗格 SHALL 显示该步骤的预览；预览 MUST NOT 修改、回滚或保存 Excel 工作簿，且 MUST NOT 作为工具结果发送给模型或写入恢复缓存、服务端、日志、设置或磁盘。

#### Scenario: 点击早期写入步骤
- **WHEN** Agent 成功完成范围写入，随后完成其他工作簿步骤，用户点击该早期操作记录
- **THEN** 任务窗格显示该写入完成瞬间的范围视觉预览，当前 Excel 工作簿的内容和保存状态保持不变

#### Scenario: 点击早期步骤保留上下文保护
- **WHEN** 用户点击不是最新步骤的操作记录
- **THEN** 任务窗格显示该步骤的只读视觉预览并进入对应历史上下文；预览不修改、回滚或保存工作簿，继续对话仍遵循既有确认保护

#### Scenario: 点击最新步骤
- **WHEN** 用户点击最新操作记录
- **THEN** 任务窗格显示该步骤的只读预览，但不会进入阻止继续对话的历史上下文锁

#### Scenario: 预览不可用或步骤未修改工作簿
- **WHEN** 步骤被拒绝、执行失败、没有可视范围，或图像捕获不可用
- **THEN** 任务窗格显示明确的只读状态说明或有限范围数据回退，且工具结果和后续 Agent 循环不受影响

#### Scenario: 清除页面会话
- **WHEN** 用户刷新或关闭任务窗格、清空恢复会话，或恢复旧展示消息
- **THEN** 所有历史视觉预览从页面内存释放，恢复接口仍只包含展示消息

### Requirement: 支持明确的常用 A1 范围
共享 Excel 工具 SHALL 接受不含工作表限定符的单个单元格、单元格矩形、整列和整行 A1 范围，并 SHALL 允许 `$` 绝对引用标记。联合范围、外部工作簿引用、命名范围和公式表达式 MUST NOT 作为工具地址执行。

#### Scenario: 自动调整连续整列
- **WHEN** 模型请求对 `N:R` 或 `$N:$R` 自动调整列宽
- **THEN** 参数校验通过并由当前工作簿执行器处理该连续整列范围

#### Scenario: 格式化连续整行
- **WHEN** 模型请求对 `1:3` 或 `$1:$3` 设置格式
- **THEN** 参数校验通过并由当前工作簿执行器处理该连续整行范围

#### Scenario: 拒绝跨工作簿或联合范围
- **WHEN** 地址包含工作表限定符、外部工作簿引用、逗号联合范围或公式
- **THEN** 系统不执行工具并向模型返回可恢复的地址参数错误
