## Why

当前模型请求必须等待完整 JSON 响应，长回答在任务窗格中会长时间没有反馈；同时操作记录按工具调用逐行平铺，用户无法快速看出一次任务包含哪些步骤。输入区在运行期间还显示“模型处理中”，发送、停止是两个并存按钮，状态切换不够紧凑。

## What Changes

- 为四种已支持协议增加本地 SSE 增量传输，并保留非流式 JSON 回退。
- 服务端按协议解析文本和工具调用增量，最终仍归一化为同一工具循环结果；工具只有在完整参数结束后才执行。
- 任务窗格实时追加助手文字，直到最终消息确认；取消请求时同时中止上游读取和本地会话。
- 将一次用户任务的所有工具步骤收拢为一个可展开/折叠的操作记录，默认折叠并显示任务摘要、步骤名和步数。
- 删除独立停止按钮；运行时发送按钮显示旋转圆环，悬停或键盘聚焦时显示停止图标并执行取消。
- 删除“模型处理中”文案，保留审批等待等需要用户决策的状态提示。

## Boundaries

- API Key、工作簿内容和上游原始响应仍不进入任务窗格以外的持久化位置。
- 本次不改变 Excel 工具 Schema、审批语义、步骤上限或协议端点的非流式兼容行为。
- 不把发布到 Microsoft Marketplace 作为本次目标。
