## Why

ChatExcel 的对话上下文目前只保存在任务窗格和本地服务进程内。任务窗格、Excel 或本地服务意外退出后，界面中的旧消息会消失或与新的模型会话脱节，用户不得不重新说明当前工作簿场景。用户需要一个仅在当前活动对话存续期内可用的本地恢复机制，以应对闪退和临时服务故障，而不是长期保存聊天记录。

## What Changes

- 为当前工作簿的活动对话增加仅限当前 Windows 用户的加密本地恢复快照，保存模型输入、已完成的工具结果、可见对话记录和必要的会话状态。
- 任务窗格重新加载或本地服务重启后恢复尚未过期的当前对话，并保留同一会话 ID 以继续后续消息。
- 使用任务窗格成功的存活心跳维持活动对话；任务窗格持续打开时即使不聊天也保留恢复快照；任务窗格或 Excel 窗口关闭或崩溃后，从最后一次成功心跳起 30 分钟自动清除。用户明确停止或重置会话时立即清除。
- 对中断中的模型请求或 Excel 工具调用只恢复上下文和中断提示，不自动重发模型请求、不自动执行或重放 Excel 写入；用户必须明确继续，模型需要重新读取或重新获得审批。
- 继续将恢复数据限制在本机、无遥测、无云同步，并使恢复缓存不与 API Key 配置文件混存。

## Capabilities

### New Capabilities

- `local-conversation-recovery`: 为当前工作簿的短期本地会话提供加密快照、恢复、心跳过期和明确删除行为。

### Modified Capabilities

- `local-addin-runtime`: 将默认不持久化任务数据的规则收窄为允许用户授权的、加密且 30 分钟过期的崩溃恢复缓存。
- `responses-agent-orchestration`: 允许会话从短期恢复快照重建，并定义中断模型步骤和工具调用的安全续接语义。

## Impact

- 受影响代码：`src/server/session-manager.js`、`src/server/http-app.js`、`src/server/index.js`、任务窗格的 API/初始化/历史状态，以及新的恢复存储模块和对应测试。
- 新增一个受 DPAPI 保护的用户本地缓存文件；不新增第三方依赖，不将模型令牌暴露给 Excel WebView，也不改变回环 HTTPS 网络边界。
