## ADDED Requirements

### Requirement: 任务窗格提供紧凑且可读的布局密度

任务窗格 SHALL 通过减少固定区和非必要留白，为对话内容保留更多可用空间；正文消息字号 MUST 保持至少 12px、行高至少 17px，桌面端常用交互控件高度 MUST 至少为 24 CSS 像素。紧凑布局不得改变现有键盘焦点、滚动、附件或 reduced-motion 行为。

#### Scenario: 400px 任务窗格使用紧凑基线

- **WHEN** 任务窗格在宽度 400 CSS 像素、高度 900 CSS 像素下打开
- **THEN** 顶部栏、操作记录、composer 和页脚按紧凑基线渲染，对话区获得比原基线更多的可用高度，且 `body.scrollWidth` 等于 `body.clientWidth`

#### Scenario: 320px 窄任务窗格不产生溢出

- **WHEN** 任务窗格在宽度 320 CSS 像素、高度 700 CSS 像素下打开，并显示消息、操作记录或附件控件
- **THEN** 文本在容器内换行或按既有规则滚动，任何核心控件不被遮挡，且页面不出现横向滚动

#### Scenario: 紧凑控件仍可操作

- **WHEN** 用户使用鼠标或键盘访问发送、审批、模式、操作记录和设置控件
- **THEN** 每个控件的可见焦点仍然存在，桌面端命中区域高度至少为 24 CSS 像素，交互状态与紧凑调整前一致
