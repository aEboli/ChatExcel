## Context

ChatEx 页脚在 28px 高度内用 CSS 地形和六个几何小人构成田野跑步彩蛋。用户提供了六张方形人物图，要求这些人物取代现有小人；任务窗格已通过本地静态资源提供图标和截图。

## Goals / Non-Goals

**Goals:**

- 让六个角色分别使用一张用户提供的本地人物图。
- 在极窄的 28px 场景中保持角色可辨认、图像不拉伸、可连续横向经过。
- 延续点击、键盘和减少动效行为，并保证没有外部网络请求。

**Non-Goals:**

- 不重绘田野背景、ChatEx 入口或任务窗格其他区域。
- 不增加图片上传、远程图片加载或人物选择界面。
- 不改变模型、服务端、Excel 工作簿或凭据处理。

## Decisions

### 将用户图片打包为本地静态角色资源

六张 PNG 复制到 `assets/easter-characters/`，并在语义化的 `<img>` 子元素上逐一引用。相对于临时剪贴板路径或远程 URL，这使安装包可独立运行，也不会将用户图像发送到网络。

### 以容器裁切和 `object-fit: cover` 适配窄场景

每个角色保留其原本的 `.easter-walker` 动画容器。容器用固定小尺寸、底部对齐和 `overflow: hidden` 裁切；图片使用 `object-fit: cover`、偏向画面下方，保留跑步主体而避免把整张方图压缩成不可识别的缩略图。

备选方案是继续用 CSS 伪元素覆盖图片，或将整幅图设为场景背景。前者会留下抽象小人，后者无法一一对应六个角色，因此不采用。

### 保留现有动画和 reduced-motion 语义

横向移动仍附着在角色容器。减少动效时容器停在各自的静态位置，图片仍可见；不对图片加入额外的持续动画。

## Risks / Trade-offs

- [方形源图在 28px 高度中可能丢失主体] → 使用底部对齐裁切、略高于旧小人的角色容器，并在 320px/400px 布局检查中核对。
- [六张源 PNG 增加包体积] → 仅打包本次提供的六张图，不引入运行时图片库或网络依赖。
- [已有 CSS 几何伪元素与图片重叠] → 移除角色伪元素的绘制规则，仅保留动画容器。
