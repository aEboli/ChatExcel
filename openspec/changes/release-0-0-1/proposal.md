## Why

ChatExcel 需要一个可识别、可复现的首个公开发行版本，同时把任务窗格里低频但有记忆点的页脚细节纳入产品体验和文档。当前 README 偏向开发记录，发行信息、技术栈和一键加载版入口不够醒目。

## What Changes

- 将应用、服务健康状态、npm 包和 Launcher 发行元数据统一为 `0.0.1`。
- 增加中英文更新日志，记录首个版本的功能边界和已知限制。
- 重排中英文 README 的首屏、发行入口、技术栈、架构、安装和验证顺序，并加入截图和动效说明。
- 在任务窗格底部增加可访问、可点击、尊重 reduced-motion 的页脚彩蛋：悬停或聚焦时显现 CSS 绘制的小物件和行走角色，点击后固定活动状态。
- 将 `0.0.1` 发行包构建为 GitHub Release 所需的 ZIP 和校验文件，并同步远程仓库标签与发布说明。

## Boundaries

- 不改变模型协议、Excel 工具 Schema、审批语义、本地服务网络边界或敏感配置存储方式。
- 页脚彩蛋不加载外部脚本、图片或字体；参考 Detail 页脚彩蛋的空间关系，但动画由仓库内 CSS 实现。
- GitHub 发布只包含源码归档和 Windows x64 发行包，不把 API Key、Codex 配置、工作簿数据或运行时日志写入仓库。
- 版本号 `0.0.1` 是本次发行标识，不修改 Office manifest 要求的 `Version` XML 结构。
